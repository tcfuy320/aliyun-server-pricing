## 38元一年的轻量服务器怎么抢

38元需要抢。每天两场秒杀，上午10:00和下午15:00，购买条件是阿里云新用户，抢到按38元成交，没抢到就是常规优惠价68元一年，折合每月5块多。

配置是2核2G、40GB ESSD系统盘、200M峰值带宽，不限月流量。有两个容易误解的点值得展开：

**先说带宽，这200M是峰值带宽。**峰值的意思是带宽上限200M，实际速度随负载浮动，忙时可能达不到。业务对带宽稳定性有硬性要求的话，这个区别直接决定你要不要选它。

## 常见问题

**38元没抢到怎么办？**
等下一场，每天上午10:00和下午15:00各一场；或者直接按68元常规价买，一年也就多30元。

**99元服务器第二年续费还是99元吗？**
是。99计划每年提供一次原价续费机会，活动有效期到2029年3月31日。

**个人用户能买199元那台吗？**
不能，199元档要求企业实名认证。个人用户选99元e实例或轻量应用服务器。

**按量付费怎么停止扣费？**
在控制台释放实例即可，释放后该实例不再产生费用。

**200M峰值带宽的速度稳定吗？**
峰值是上限值，实际速度随负载浮动，忙时可能达不到200M。对带宽稳定性要求高的业务，选固定带宽的ECS更合适。
